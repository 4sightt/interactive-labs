# Interactive Labs

Small browser-based experiments and judgment-training tools.

## Rule Hunter

Rule Hunter is a finite-hypothesis inference game. A hidden rule is selected from a fixed set of candidate rules. Test triples of integers, eliminate inconsistent hypotheses, and design a final discriminating experiment when two candidates remain.

- Source: `rule-hunter/index.html`
- Play URL after GitHub Pages is enabled: `https://4sightt.github.io/interactive-labs/rule-hunter/`

More interactive tools can be added as separate folders under this repository.
